# Incident Response Field Guide

A responsive, single-page educational website for a beginner classroom activity on incident response.

## Site details
- Explains the six-phase response lifecycle: prepare, identify, contain, eradicate, recover, and learn.
- Includes an interactive first-actions checklist and a fictional scenario with feedback.
- Offers three provisional classroom activities: fact vs. assumption, containment decisions, and an after-action review.
- Static HTML/CSS/JavaScript; no login, backend, analytics, or incident-data collection.
- Educational only. Follow the organization's approved process for real incidents.
