# Replit Vibe-coding prompt: Incident Response Field Guide

Build a responsive, beginner-friendly educational website called Incident Response Field Guide for a classroom assignment.

## Audience and goal
Students learning what incident response is and how to respond calmly and responsibly. Explain the standard response lifecycle in plain language and make the next step easy to understand.

## Build requirements
- Create a polished single-page website that works on phones and desktop.
- Use semantic HTML, accessible labels and contrast, clear headings, and keyboard-friendly interactions.
- Include an introduction, six phases (prepare, identify, contain, eradicate, recover, learn), and a first-actions checklist.
- Add one fictional interactive scenario with a clear explanation of the safer response.
- Add three brief classroom activities: fact vs. assumption, containment decision discussion, and after-action review.
- Keep it static and self-contained; no login, backend, analytics, external services, or form that collects incident information.
- State that the site is educational, not operational policy; direct real incidents to the user's approved response plan and authorized responders.
- Do not request or display real credentials, personal data, or confidential incident details.
- Use a calm, practical tone; avoid alarmist language and unsupported promises.

## Deliverables
Create index.html with the complete working site and README.md with the site purpose, how to preview it, and the public repository-folder link. Keep the code simple enough for a beginner to explain in class.

## Classroom slide alignment
The lecture slides were not included with this request. Treat the three activities above as provisional suggestions, and update them to match the instructor's actual three lessons when the slides are provided.
